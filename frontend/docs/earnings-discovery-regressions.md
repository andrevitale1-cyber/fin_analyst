# Transcript discovery and quote request reliability

The CAVA Q1 FY2026 public transcript is available at https://stockanalysis.com/stocks/cava/transcripts/569001-q1-2026/. The prior direct-archive fallback was gated by a short issuer alias list, excluding CAVA and other US tickers. Discovery now applies to syntactically valid US symbols, including share classes, while retaining issuer and fiscal-quarter validation and existing web fallback. Index summaries cannot be returned as full transcripts. Archive links for another period and stock paths for another issuer are rejected. Company names with normal corporate punctuation are accepted and resolved to a ticker. Verified transcripts continue to use the existing cache; diagnostic logs distinguish found, unavailable source and not found.

Live fetch-only checks found CAVA Q1 FY2026, CAVA Q1 FY2025 and Starbucks Q1 FY2026 in roughly 0.8–1.5 seconds on the development connection, with paid search blocked in the test. This is an observation, not a latency guarantee. No new analysis was generated or charged.

Render logs for the reported Microsoft session showed overlapping quote/history requests and HTTP 429 responses from Twelve Data. Quote components no longer refetch merely because Clerk returns a new getToken function. The backend serializes concurrent requests for the same symbol, caches its quote across chart ranges, and falls back to an issuer-verified Yahoo Finance snapshot when the primary source lacks usable data. Failed snapshots expire sooner than successful ones. Attribution and quote/history remain from the same selected source. The recent-analysis list selects the latest entry per company, avoiding repeated company cards; the main report retains a single full chart.

Validation: 22 market-data tests and 21 selected transcript discovery/validation regressions passed, including concurrent requests, source fallback, wrong-company rejection, exact-quarter archive selection and cache reuse. Production frontend build and latest TypeScript check passed. Broader API-route tests were not included in this focused run. The Microsoft saved analysis is used for UI verification without generating another analysis.
